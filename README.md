# The World Today — Sunday, 22 November 2026

A one-page newspaper front page summing up 22 November 2026 in one image.
`main.ts` (Node 22, standard library only) draws the page procedurally — masthead,
date line, and three stories — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`
as a deterministic 1024x1024 PNG.

The three stories: Mexico captures cartel boss "El Chapo Isidro" in Sinaloa;
Trump, Xi and Putin meet in Shenzhen; COP31 runs into a second day of overtime
in Antalya.
